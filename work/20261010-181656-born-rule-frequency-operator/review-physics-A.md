## Issues
- [major] "Observed, for θ = 30°: ... (Grangier, Roger and Aspect, 1986, measured" — this stitches several experiments into one that was never performed as described. GRA 1986 used an atomic-cascade (calcium) source, not a crystal, and a 50/50 splitter, not a polarizer at 30° followed by a polarizing splitter. In Experiment 2, the cited generators (Jennewein et al. 2000; Stefanov et al. 2000) used strongly attenuated LED or laser light, not heralded photons. The skill requires experiments to be described as they were actually performed. Fix: separate the experiments. "GRA (1986), atomic-cascade heralded photons on a 50/50 splitter: double-firing ratio 0.18 ± 0.06. Thorn et al., Am. J. Phys. 72, 1210 (2004), crystal-pair heralded photons, a half-wave plate and a polarizing splitter: far below 1. Malus cos²θ curves with heralded photons in teaching labs (Beck; Dehlinger & Mitchell). θ = 30° is our worked example." For Experiment 2: "faint LED/laser light, attenuated so that more than one photon at a time is rare."
- [major] "All three give identical predictions for every count in both experiments" — this overstates what model 2 delivers, and the candidate's own text contradicts it. The frequency operator yields only the N = ∞ frequency. The finite-N run statistics (the scatter table, 1/√N) follow only "under the Born reading", as the candidate itself says twice. Fix: "None of them disagrees with any count. Model 1 predicts the finite-run statistics directly. Models 2 and 3 recover them only when squared length is read as chance; on their own terms they fix only the infinite-run frequency." In the same spirit, the model 2 Pro "No probability postulate" should read "no probability postulate beyond the certainty rule (contested, see (i))".
- [major] "each photon's arrival splits the world, and after N photons there are 2^N branches" — this presents DeWitt's 1970 counting picture as the many-worlds reading itself. Branch counting is then offered as a live alternative to weight, with only the Kent/Barrett objection on the other side. That is uneven. In decoherence-based Everett (Wallace 2012, ch. 4) branching happens at registration or decoherence, not at "arrival". On that view branch number is not well defined (it depends on coarse-graining), and that is the main reason Everettians reject counting. Fix: "In DeWitt's version, each detection splits the world..." Then add after the count table: "Modern Everettians reply that the number of branches has no fixed value (it changes with how finely decoherent branches are divided), so counting is not an available rule. Critics answer that this makes the weight rule harder, not easier, to justify."
- [major] "only the 2-norm is kept fixed by continuous lossless change (the Banach–Lamperti theorem)" — false as written. Continuous phase changes on each component keep every q-norm fixed. The theorem says that for q ≠ 2 the only linear maps preserving the q-norm are permutations with phases, so no continuous norm-preserving change can *mix* outcomes. Fix: "only for the 2-norm are there continuous, reversible linear changes that mix the outcomes while keeping the norm fixed (Banach–Lamperti; for q ≠ 2 such maps can only permute outcomes and change phases)". In the same sentence, "Gleason's theorem fixes the square among all rules" leaves out non-contextuality. Add "for any rule that is non-contextual (as defined in the table below)". Note also that Gleason does not apply to this two-outcome polarizer.
- [minor] "Dürr, Goldstone & Zanghì 1992" (comparison table) — the author is Sheldon Goldstein; Goldstone is the FGG author. The Sources line spells it correctly. Fix the table.
- [minor] Figure a-deviant-length caption "every curve falls toward zero as N grows" — for N from 10, the exact deviant weight is jagged and non-monotone at small N. Example: ε = 0.05 gives about 0.47 at N = 10 but about 0.74 at N = 11, because the set of allowed fractions m/N changes with N. Fix: "the exact curves are jagged at small N (the allowed fractions m/N change with N) but trend to zero much faster than their bounds; the bounds exceed 1 for small N and are then empty."
- [minor] Sources gaps. "Barrett (1999)" is cited in model 3 but missing from its Sources line; add Barrett, *The Quantum Mechanics of Minds and Worlds* (OUP, 1999). Sakurai & Napolitano 3rd ed. §1.3 is "Base Kets and Matrix Representations"; the measurement postulates are in §1.4. Cite "§1.4" for the postulates, or label §1.3 correctly.
