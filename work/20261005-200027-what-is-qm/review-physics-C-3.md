## Issues
- [major] Figure strip title "glowing hydrogen, as actually seen" — False as a label, and it contradicts C's own caption. The widened strip now shows lines between 365 and 380 nm, which are ultraviolet and cannot be seen by eye. They are also drawn in a visible purple. The caption says "brightness only suggested", but "as actually seen" claims the brightness is real. The round-2 review asked for a new title, and that part of the fix was not applied. Fix: retitle "glowing hydrogen: line positions to scale (brightness only suggested)". Put a "UV" label in the shaded 360–380 nm band of this strip as well, as the classical strip already has, and draw the UV lines in grey rather than violet.
- [major] "every atom of ordinary hydrogen has the same allowed energies" (lines 3 and 9, and "every atom of ordinary hydrogen has the same one" on line 17) — The isotope problem is fixed, but the claim is still an absolute with an unnamed idealization. Hydrogen atoms in a magnetic or electric field have shifted and split rungs (Zeeman and Stark effects). Astronomers use exactly this to measure magnetic fields in sunspots and stars. The claim holds for atoms left undisturbed, and C already uses that framing on line 23 ("In an atom left alone"). Fix: line 3 "why every undisturbed atom of ordinary hydrogen has the same allowed energies"; line 9 "Every atom of ordinary hydrogen, left undisturbed, has the same allowed energies"; line 17 "so every undisturbed atom of ordinary hydrogen has the same one".
- [minor] "radiates light (that's how radio antennas broadcast)" — True only if "light" means all electromagnetic radiation. A conceptual learner will read "light" as visible light and be puzzled by the radio example. Fix: "radiates electromagnetic waves, the family that includes light and radio (that's how radio antennas broadcast)".
