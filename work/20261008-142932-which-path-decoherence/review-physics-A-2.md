## Issues
- [major] Figure a-leaked-tag, axis "N, number of particles the tag has spread into"; a-relate-map box "decoherence: tag spread into very many particles (overlaps multiply)". Both labels say what round 1 flagged as critical: that spreading multiplies the overlaps. The body text is now correct, because only particles that each scatter off the molecule lower the stripe strength, and later spreading leaves the overlap unchanged. The a-leaked-tag caption even says "The axis label says …; read N as …", which admits that the label is false. The learner sees the label first, and section 0 holds figures to the same standard as the text. Fix: redraw a-leaked-tag with the axis "N, particles that have each scattered off the molecule (independently, same overlap p)", and drop the "read N as" sentence from the caption. Change the a-relate-map box to "decoherence: very many particles each scatter off the object (overlaps multiply); the record then spreads beyond collecting".
- [major] Figure a-erasure-views, collapse panel: "erasure works exactly as in standard theory". This is false, and it is the same error round 1 flagged in the text. The text now says "indistinguishably … far below anything measurable", but the caption only patches the figure ("Read the collapse panel's 'exactly as…' as…"). In the same family, the a-relate-map caption says "collapse differs only for records far larger than these", but collapse models differ for single atoms too, by an unmeasurably small amount. Fix: change the panel text to "erasure works indistinguishably from standard theory (difference far below measurable)" and delete the patch sentence in the caption. Change the a-relate-map caption to "collapse differs measurably only for records far larger than these".
- [minor] Figure a-same-situation, column 3 header: "tag, then partner measured along the halfway direction". The atom has no partner. For the photon pair, the partner's diagonal polarizer is a measurement on one photon. It is not the "halfway direction" between the two joint tag states. The text caption gets this right: "for the atom, along the halfway direction; for the photon pair, the partner's diagonal polarizer". Fix the header to "tag, then measured so that both results are equally likely whichever slit was used".
- [minor] "a tag that is rotated back makes the two parts … overlap again, and both steer the atom again". In pilot-wave theory with an internal-state tag, both parts of the wave contribute to the atom's velocity even while the tag is written. What the tag removes is the cross term between them, that is, their interference in the steering. "Both steer … again" implies that one part stopped steering. Fix: "…and their contributions interfere in the steering again, so the stripes return".
- [minor] Figure a-erasure-views, many-worlds panel: "a one-photon tag has not split the world". In the photon experiment the tag sits in the pair's joint polarization, not in one photon, and the atom's tag is in one atom. Fix: "a tag in one atom or one photon pair has not split the world" (this matches the text).
- [minor] "one glancing collision, which barely deflects a heavy molecule, is a near-perfect tag". Whether a collision is a tag depends on its momentum transfer q compared with ħ/(path separation), not on the gas atom's wavelength alone. An extremely forward collision with q below ħ/Δx is a weak tag. The claim holds for essentially all real collisions in Hornberger et al., but "glancing" invites the wrong case. Fix: "even a collision that barely deflects the heavy molecule is a near-perfect tag, because the gas atom's momentum is so large compared with what is needed to tell paths a micrometre apart".
